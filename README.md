# 일흔여덟 장 타로

뒤집힌 카드 더미에서 카드를 직접 골라 타로를 보는 한 페이지짜리 웹사이트예요.

- 배치: 오늘의 한 장, 과거·현재·미래, 상황·행동·결과, 나·상대·관계, 마음·몸·영혼, 강점·약점·조언, 켈틱 크로스
- 카드 뭉치 구성: 전체 78장 / 메이저만 / 마이너만 / 수트별 선택
- 역방향 포함 여부 선택, 리딩 결과 복사, 78장 카드 사전

## 출처

- 카드 키워드와 배치법: [Biddy Tarot](https://biddytarot.com/tarot-card-meanings/)을 참고해 한국어로 새로 정리했어요. 해석 문장은 원문 번역이 아니라 새로 쓴 글이에요.
- 카드 그림: 1909년 Rider-Waite-Smith 덱(그림 Pamela Colman Smith)의 퍼블릭 도메인 스캔, [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:RWS_Tarot_00_Fool.jpg).

타로는 재미와 자기 성찰을 위한 도구로 즐겨 주세요.
